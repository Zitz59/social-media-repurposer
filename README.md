# Social Media Repurposer

Reworks any text in an article for LinkedIn, Twitter, or a video description on YouTube

### 🔗 ** [Live Demo](https://social-media-repurposer.vercel.app/)

![Demo](https://raw.githubusercontent.com/Zitz59/social-media-repurposer/main/public/demo.gif)

## Features

- Transcript input
- AI summaries
- LinkedIn post generation
- Twitter/X post generation
- YouTube description generation

## Tech Stack

- Next.js 16
- TypeScript 
- Tailwind CSS
- Anthropic API
- React-icons
- Zod

## Getting Started

1. Clone the repository
2. Install dependencies: `pnpm install`
3. Create `.env.local` file in the root:
\```
ANTHROPIC_API_KEY=your_api_key_here
\```
5. Run: `pnpm dev`
